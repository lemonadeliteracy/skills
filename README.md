# Skills for working with AI

This repository brings together instructions, called **skills**, that can help you work with an AI coding agent as you build an app.

- **Interview me** helps you think through an idea before you build.
- **Handoff** helps you record the context another agent needs to continue your work.
- **Setup Matt Pocock's skills** configures a project for his engineering skills.
- **To spec** turns a discussion into a specification in the project's issue tracker.
- **Prototype** explores a design question using a temporary working example.
- **Wait, what?** asks the agent to explain its last message again.

Start with the [skills index](index.md) to learn when to use each one and see the original files.

These skills are shared unchanged from their creators. Their instructions are not a guarantee that an agent will make the right decision. Review its questions and output, and don't share private information or credentials.

Using these skills with Codex and Claude Code in the course's browser-based Codespace has not yet been tested. Installation and automatic skill discovery may differ between agents.
